# ShopEase E-Commerce Website

A responsive, front-end e-commerce website built with vanilla HTML, CSS and JavaScript.

## Features
- Responsive desktop/tablet/mobile layout
- Product catalog with 16 demo products
- Search
- Category filtering
- Sorting by price/rating
- Wishlist with localStorage
- Shopping cart with quantity controls
- Persistent cart/wishlist
- Demo checkout modal
- Responsive navigation
- Promotional hero and sale section
- No build step required

## Run
Open `index.html` in any modern browser.

This is a front-end demo. The checkout does not process real payments and the product data is stored in `script.js`.
